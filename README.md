# 🔍 Inverted Search Engine in C

This project implements an inverted index for fast text search using hash tables and doubly linked lists. Designed to handle 1000+ files and provide instant keyword-based lookups.

---

## 📦 Features

- Indexes words from multiple files
- Stores file locations using a hash table and linked list
- 3x faster than linear search
- Menu-based CLI

---

## 🧰 Tools

- Language: C
- Data Structures: Hash Table, Doubly Linked List
- File I/O
